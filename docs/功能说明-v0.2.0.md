## 1. 系统架构总览

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────┐
│                    Web 浏览器                        │
│  ┌─────────────────────────────────────────────────┐│
│  │              index.html (入口)                   ││
│  │  ┌─────────┐ ┌──────────┐ ┌──────────────────┐ ││
│  │  │ 侧边栏   │ │  中栏    │ │  右栏（内容区）   │ ││
│  │  │ 导航     │ │ 智能体   │ │  聊天/页面内容    │ ││
│  │  └─────────┘ └──────────┘ └──────────────────┘ ││
│  │  ┌─────────────────────────────────────────────┐││
│  │  │ 独立页面容器（session/memory/config/...）    │││
│  │  └─────────────────────────────────────────────┘││
│  └─────────────────────────────────────────────────┘│
│  JS: app.js → dom.js / chat.js / pages/*.js         │
│  WS: 实时通信  |  HTTP: REST API                     │
└─────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────┐
│              siper_web.py (Python 后端)              │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │
│  │ WS Handler   │ │ HTTP Router  │ │ Agent Runner │ │
│  │ (WebSocket)  │ │ (REST API)   │ │ (AI Core)    │ │
│  └──────────────┘ └──────────────┘ └──────────────┘ │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │
│  │ Session Mgr  │ │ Models DB    │ │ Skill System │ │
│  │ (SQLite)     │ │ (SQLite)     │ │ (文件系统)   │ │
│  └──────────────┘ └──────────────┘ └──────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 层级 | 技术 | 文件 | 行数 |
|------|------|------|------|
| 前端 HTML | HTML5 + 内联模板 | `webui/index.html` | 420 |
| 前端 CSS | CSS3 + CSS 变量 + Grid/Flex | `webui/css/style.css` | ~1222 |
| 前端 JS | 原生 ES Module（无框架） | `webui/js/` 下 20+ 文件 | ~6863 |
| 后端 | Python 3.10+ / asyncio | `siper_web.py` | 4192 |
| Agent 核心 | Python / 工具调用链 | `ai_agent/core/agent.py` | 1910 |
| 数据库 | SQLite（WAL 模式） | sessions.db / models.db / token.db | - |
| 通信 | WebSocket + HTTP REST | siper_web.py | - |
| 依赖 | openai / websockets / jinja2 | setup.py | 3 个必须 |

## 2. 侧边栏导航

### 2.1 功能描述

左侧导航栏，提供页面切换入口。支持折叠/展开。

### 2.2 UI 结构

```
┌──────────────────┐
│ 🎭 SiPer      ← 点击折叠/展开 │
├──────────────────┤
│ ▸ 智能体          │
│   💬 对话         │ ← 当前页面高亮
│   📋 任务         │
├──────────────────┤
│ ▸ 支持           │
│   🤖 模型         │
│   🔧 工具         │
│   🧩 技能         │
│   🔌 插件         │
├──────────────────┤
│ ▸ 监控           │
│   📊 监控         │
│   ⚙️ 全局         │
└──────────────────┘
```

### 2.3 功能清单

| 功能 | 状态 | 说明 |
|------|------|------|
| 折叠/展开侧边栏 | ✅ | `toggleChatSidebar()`，图标切换 |
| 页面导航高亮 | ✅ | 当前页面 nav-item 加 `active` class |
| 导航分组 | ✅ | 智能体/支持/监控 三组 |
| 图标+文字 | ✅ | 每个导航项有 emoji 图标和文字标签 |
| 国际化 | ✅ | 文字标签支持中/英切换 |

### 2.4 导航项定义

| 页面 ID | 图标 | 中文 | 英文 | 页面类型 | 说明 |
|---------|------|------|------|---------|------|
| chat | 💬 | 对话 | Chat | 对话家族 | 三栏布局对话页 |
| tasks | 📋 | 任务 | Tasks | 对话家族 | 任务管理（占位） |
| model-settings | 🤖 | 模型 | Models | 对话家族 | 模型配置 |
| tools | 🔧 | 工具 | Tools | 对话家族 | 工具管理（占位） |
| skills | 🧩 | 技能 | Skills | 对话家族 | 技能管理 |
| plugins | 🔌 | 插件 | Plugins | 对话家族 | 插件管理（占位） |
| monitor | 📊 | 监控 | Monitor | 对话家族 | 系统监控 |
| global-settings | ⚙️ | 全局 | Settings | 对话家族 | 全局设置 |

### 2.5 现有问题

- tasks/tools/plugins 页面为空占位符
- 所有页面都通过 `chatSwitchPage()` 切换，共享同一个渲染逻辑
- 独立页面（sessions/memory/agent-config/theme）通过 `navigateToPage()` 切换，使用模板克隆

## 附录 C：重复代码分析

### 前端重复模式

1. **fetch + 渲染模式**：每个页面都有 `fetch('/api/xxx') → innerHTML` 的重复模式
2. **loading 状态**：每个页面都有 `innerHTML = '加载中...'` → `innerHTML = '加载失败'` 的重复
3. **表单保存模式**：agent-config 中每个 input 都有 `oninput → triggerAgentAutoSave()` 的重复
4. **Tab 切换模式**：多个页面有类似的 tab 切换逻辑
5. **搜索过滤模式**：多个页面有搜索 + 过滤逻辑

### 后端重复模式

1. **API 路由分发**：siper_web.py 中 50+ 个 if/elif 路由判断
2. **数据库 CRUD**：每个数据模型都有类似的增删改查
3. **WS 消息发送**：多处 `await ws.send(json.dumps({...}))` 重复
